# Dawaa Guide — Saudi Medicine Reference Website

A responsive, static bilingual (English/Arabic) website starter focused on medicine information in Saudi Arabia. It is built with plain HTML, CSS, and JavaScript and can be hosted as a static website (for example, GitHub Pages).

## Run locally

Open `index.html` in a browser. No build step or package installation is required.

## Publish with GitHub Pages

In the repository settings, open **Pages**, select the `main` branch and `/ (root)` as the publishing source, and save. GitHub Pages will provide the website URL when deployment is ready.

## Medicine data and safety

The directory currently contains a small set of generic-name starter entries for demonstrating search and filtering. It is **not** a complete list of medicines marketed or registered in Saudi Arabia, and it does not contain verified Saudi product labeling, dosages, safety instructions, interactions, or approval status. Do not treat the sample entries as prescribing advice.

Before adding product-level facts, confirm them against current SFDA-approved records and product leaflets, record source links and review dates, and establish an ongoing review process. Never claim that a catalogue is complete or 100% accurate without a maintained, authoritative data feed and appropriate verification.

The site links to the [Saudi Food and Drug Authority](https://www.sfda.gov.sa/en). Content is for general education only and is not a substitute for professional medical advice.
